# 资源所有权与释放

所有进程、用户映射和打开文件对象的读写由启动核在 SIE=0、内核页表生效时执行。其他 hart 处理设备中断。页池与堆节点池的短临界区各用本身的锁，锁不跨上下文切换。父子可共享物理帧和打开对象；父子用户页表树、内核栈、trapframe 和堆区间节点各自独占。

| 资源 | 获取、持有与转移 | 释放及失败责任 | 验证 |
| --- | --- | --- | --- |
| 固定用户帧与 PCB 的 \`code/data/ustack\` | \`proc_allocate\` 为新进程分配或为 fork 获取引用。PCB 字段与对应 PTE 是同一份所有权。COW 分离或 exec 由 \`install_user_frame\` 同时更新二者 | 未发布子进程由 \`proc_destroy\` 按字段释放，即使叶子未建。exec 和 COW 替换先写 PTE 并刷新 TLB，再归还旧引用。RX 代码共享时保持 RX | 引用数、PA、PTE 权限、跨页代写、exec 同伴内容 |
| 堆用户帧 | \`user_heap_alloc\` 分配清零后建叶，\`user_heap_clone\` 成功映射后每叶获取一个引用。无 PCB 帧别名。COW 只替换对应叶 | \`vm_unmappages\` 先验证整段，清叶及刷新本地 TLB 后释放引用。销毁和 exec 调 \`user_heap_destroy\`，包括未完成的子堆 | 活跃帧数、页池余额、部分解除映射、引用持有者仍可访问 |
| 用户物理帧的最后归还 | \`page_alloc\` 在用户页池锁内置一，\`page_retain_user\` 在同一锁内增引用 | \`page_free\` 取锁减引用。只有使计数变零的调用负责填充并重新放入空闲链表。该帧在填充期仍不可重新分配 | 共享时释放一次不会增加空闲数；最后释放增加一 |
| 私有页表树 | \`proc_allocate\` 获得根，\`sv39_walk\` 为其分配并连接中间表。叶只描述映射，内核只建立一套独立页表树给每个进程 | \`sv39_prune_empty\` 回收清叶后的空子树；\`sv39_free_tables\` 只归还节点，负责回滚部分建表。exec 复用现有根和固定叶位置 | 独立根及路径、分配故障点、表页计数 |
| trapframe | \`proc_allocate\` 分配私有内核页，fork 拷贝整数现场并把子返回值置零 | exit 保留直到 wait 在另一栈销毁。exec 重置内容并保留该帧。半成品由 \`proc_destroy\` 回收 | 独立地址、页池计数、fork/exec ABI |
| 内核栈及 guard | \`proc_allocate\` 分配私有栈，以槽号选择 VA。用户表与共享内核表均使用同一 supervisor-only 别名，guard 保持空洞 | \`proc_destroy\` 清共享内核栈叶后刷新本地 TLB，释放用户表再释放栈帧。就绪前失败用 \`stack_mapped\` 判定是否撤销 | guard/他进程栈不可见、槽复用、类别分配统计 |
| 堆区间节点 | \`region_alloc\` 从静态锁保护池取用。各 PCB 独立拥有链表，fork 复制节点，exec 准备新链表后转移 | 拆分/合并按事务顺序预留或回收，\`user_heap_destroy\` 归还整条链。失败由创建者释放已预留节点 | 128 节点耗尽及部分克隆失败、释放前后余额 |
| 文件描述符与共享打开对象 | \`assign_file\` 为每次 open/dup/fork（含静态 console）安装描述符并取得引用。每 PCB 有 16 个描述符，可指向同一打开对象并共享偏移。动态表 48 项 | \`close_file\` 解除绑定并减引用。exit 的 \`files_drop\` 当场释放，最后引用使动态槽可复用。exec 保留描述符，未发布子项由 \`proc_destroy\` 清理 | Lab 9 描述符/对象耗尽、共享偏移、退出后重开 |
| cwd | \`chdir\` 写入已验证目录 inode 号，fork 继承数值，exec 保留。由 \`proc_cwd_busy\` 阻止删除正在使用的目录 | exit 清零。未发布子进程的字段随 PCB 清空。目录号没有额外分配的引用对象 | Shell cd、打开文件与 cwd 跨 exec 保留 |
| PCB 及父子关系 | \`proc_allocate\` 以 USED 占槽。成功 fork 最后填写父指针/PID 并发布 RUNNABLE | exit 重新收养子孙、保留状态及地址空间成为 ZOMBIE 并唤醒父进程。wait 成功写状态后在父栈销毁；坏指针或 COW 分配失败保留僵尸供重试 | 16 槽耗尽、孤儿收养、失败不发布、循环回收 |

用户堆的空闲区间与映射互补。fork 准备子堆时仍扫描完整虚拟区间；父表权限提交使用区间补集，只访问已映射页面。释放旧堆仍扫描完整区间，逐页撤映射和修剪表。

用户 store 缺页分离失败时，普通子进程走既有 fault 路径并以 -1 退出。PID 0 仍遵循项目的 init 故障停止约定。系统调用代写遇到 OOM 返回 -12，非法用户范围返回 -14；跨页代写预留失败不改变已有页面或权限。文件读发生代写失败时共享文件偏移保持原值；console 在取走输入前先解决可能的 COW。
