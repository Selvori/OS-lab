# 三路实验结果

主场景为 8 MiB 分散写 4 页，一个模板运行 64 个分支。每次重启 QEMU 后在同一来宾中配对三种策略，每种先预热 2 轮，12 次重启交替正反顺序。每次任务耗时包括建立和最终释放。

| 路径 | 12 个批次的摊销中位数（ms/任务） | 中位吞吐（任务/秒） |
| --- | ---: | ---: |
| 批量 COW | 1.4249 | 702 |
| 共享表逐项持有 | 1.1197 | 893 |
| 模板持有 | 0.3032 | 3298 |

模板持有减逐项持有，每批配对差的中位数为 -0.8072 ms/任务，95% bootstrap 区间 [-0.8226, -0.8029]。以一次独立开机的配对批次为重采样单位，固定种子，重采样 20000 次。

## 主场景的成本分解

## 长寿分支

创建者关闭模板并撤去原堆映射后，最后一个分支覆盖全部 2048 页，再持有 5 个时钟节拍。文件标记同步采样次序。相对于分配原堆之前，三条路径依次占用以下额外用户页 / 内核页。

批量 COW 2048 / 11、共享表逐项持有 4096 / 23、模板持有 4096 / 23。任务结束后逐类资源余额恢复。
