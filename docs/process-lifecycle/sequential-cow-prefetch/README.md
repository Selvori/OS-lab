# 普通私有堆顺序写提前分离

8 MiB 私有堆写遍时，QEMU 上从 fork 到 wait 的整轮中位数从 **30.181 ms 降到 15.675 ms（−48.1%）**。复测基线为 **28.896 ms**，候选相对复测仍下降 **45.8%**。三个批次的候选中位数都低于对应基线批次。保留为顺序密集写负载的研究候选，继续在独立分支评估。

## 实现

基线为第四轮归档提交 e7fba499f66d07a601dc24007718edb226b03f08，与 c791c85 的内核、构建和基准代码一致。候选实现为 c614c2a8244b4ac5884d085951f216d4348c0ce6。

用户 store page fault 进入原有 COW 路径。必需页完成分离后，普通子进程才检查本次缺页位置。首次缺页只记录下一相邻页。若同一个 Sv39 末级表窗口内命中预测，继续尝试最多四个紧邻的有效 U/R/COW 堆叶，只复制仍有多个引用的帧。成功后记录第一个未分离的地址。空洞、权限不符、引用已独占、窗口尾或可选页分配失败都会结束本次尝试。

已复制的每页沿用 COW 的 PTE 发布、本地 sfence.vma、原帧减引用顺序。页表和用户进程由同一启动 hart 管理，内核页表下、关本地中断处理。固定页、模板与 wait 等内核代写走原有路径。新 PCB 从零状态开始。成功 mmap、munmap、exec 替换堆或重新提交父堆 COW 时清掉预测。

## 同输入对照

现有计数器已区分用户 trap 和内核代写。所有成功轮次中，成功提前分离数等于复制提交与原地升权提交之和，减用户 COW 缺页与内核 COW 代写各自的页数。普通 fork 场景逐样本核对没有原地升权。写序列由用户程序给定，候选提前分离数减去被省掉的缺页数即可得到提前复制后未写的页数。来宾冒烟另外直接检查了 PTE 和帧引用。

普通 fork 场景每轮另有一次父进程 wait 状态代写，计入峰值和复制字节。8 MiB 全写两版均复制 8,392,704 B（2048 个堆页及 1 个 wait 状态所在页），额外内核页峰值均为 11，wait 后计数构建剩余 22107 个用户页、7934 个内核页、126 个堆节点，使用 2 个 PCB、0 个打开对象。每批结束也通过释放预热堆后的资源余额检查。立即 exec 场景计数中的 1 次用户 COW 缺页来自固定页路径，提前分离为 0。

## 边界和代价

- 来宾冒烟连续四轮通过。写两页即停时记录 2 次实际缺页、4 次提前分离，四页均未写。验证了新子进程首次缺页、原内容及页尾复制、父子隔离、窗口边界、已可写叶、稀疏洞后实际写入，以及双页池、节点和对象余额。
- 单次分配失败注入让必需页及第一个提前分离页成功，第二个提前分离失败。当前用户 store 成功返回，失败位置和后续叶仍共享，其后一次实际写入成功。已有生命周期来宾回归的 8 轮覆盖必需 COW 分配失败杀掉故障子进程及其他回滚。模板专项和三种钉住页检查通过。
- 正式 QEMU build/run 进入双 hart 的 Shell，可执行 pwd 并正常退出。QEMU、VisionFive 2 ELF 入口分别为 0x80200000、0x40200000，FIT 通过 dumpimage 检查。开发板运行、实际硬件缺页成本、内核关中断停顿尾部和长期内存压力尚未测量。
- 主负载的复制量和峰值没增加，收益集中在连续写遍。短前缀会提前复制未写页。8 MiB 分散写和 64 KiB 只读的中位数上浮，分布重叠。继续研究前，值得以相同地址序列比较固定预分离与此触发策略，并测真实设备和关中断停顿。
